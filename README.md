📌 su putrizahra
Berarti: Switch user ke putrizahra, tanpa memuat environment shell sepenuhnya.
Hanya mengganti user, tapi environment (PATH, HOME, variable, dll) tetap milik user sebelumnya.
Misalnya: kamu tetap di direktori awal user sebelumnya (/home/putizahra), bukan home direktori putrizahra.
Tidak menampilkan pesan sambutan dan informasi shell lengkap dari .bash_profile atau .profile.

📌 su - putrizahra
Berarti: Switch user ke putrizahra seperti login baru, atau "login shell".
Environment akan dimuat seperti ketika putrizahra login dari awal:
Direktori berubah ke ~putrizahra
Variabel environment dan PATH dimuat dari .bash_profile, .profile, dll
